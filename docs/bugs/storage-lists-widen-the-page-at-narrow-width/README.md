# storage-lists-widen-the-page-at-narrow-width

At narrow widths the Storage page's clean-ups and System Data lists were wider than their card, so the whole page scrolled sideways. Each list now scrolls inside its card.

| File | What it holds |
|---|---|
| [detail.md](detail.md) | What was seen, how to reproduce, the cause |
| [resolution.md](resolution.md) | The fix and how it was checked |
